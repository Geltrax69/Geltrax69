## About Geltrax

I'm **Harsh Khajuria**, building under the handle **Geltrax69**. I make things that actually run — web apps, native macOS/iPad apps, games, simulations, and AI-generated visuals — and I ship them to public repos instead of letting them rot in a drafts folder.

This profile currently hosts **68 public repositories** across **JavaScript, Swift, Java, TypeScript, Python, C#, and more**. I treat design, build, and deploy as one job, not three.
